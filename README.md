# Мої лічильники

Облік показників лічильників (електрика, газ, вода, опалення) з нагадуваннями і подачею показників Telegram-ботам постачальників від вашого імені.

- Дані зберігаються лише в браузері (localStorage). Для перенесення на інший пристрій є «Резервна копія» / «Відновити» внизу сторінки.
- Нагадування: файл `.ics` з щомісячними подіями на перший і останній день подачі.
- Telegram: сайт входить у ваш акаунт через MTProto ([GramJS](https://github.com/gram-js/gramjs)) прямо в браузері. Потрібні `api_id` і `api_hash` з [my.telegram.org/apps](https://my.telegram.org/apps). Ключі й сесія лишаються в localStorage цього браузера.

## Сценарій бота

Кроки, які ви робите в боті вручну, по одному на рядок:

```
надіслати /start
натиснути Передати показник
надіслати {рахунок}
надіслати {показник}
очікувати прийнято
```

Дії: `надіслати`, `натиснути` (текст кнопки, достатньо частини), `очікувати` (слово з відповіді бота), `пауза N` (секунди). Підстановки: `{показник}` (ціле), `{показник_точно}`, `{рахунок}`, `{дата}`.

## Розробка

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # збирає dist/
```

Пуш у `main` публікує сайт на GitHub Pages через `.github/workflows/pages.yml`.
